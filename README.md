# IP Address Classification and Analysis

This repository contains the results of an IP addressing exercise, covering IPv4 classes and IPv6 categories.
These exercises were completed as part of the **Cybersecurity course at Jedha**

## Part 1: IPv4 Classification
- 10.0.45.2 - Class A, Private
- 172.20.10.5 - Class B, Private
- 192.168.100.200 - Class C, Private
- 8.8.4.4 - Class A, Public
- 203.0.113.15 - Class C, Public (Documentation)
- 127.0.0.1 - Class A, Private (Loopback)
- 224.5.6.7 - Class D, Private (Multicast)
- 240.0.0.1 - Class E, Private (Experimental)
- 169.254.1.1 - Class B, Private (Link-Local/APIPA)
- 198.51.100.25 - Class C, Public (Documentation)

## Part 2: IPv6 Classification
- 2001:db8::ff00:42:8329 - Public, Global Unicast (Documentation)
- fe80::1 - Private, Link-Local
- fc00::1234:abcd - Private, Unique Local
- ::1 - Private, Loopback
- 2001:4860:4860::8888 - Public, Global Unicast
- ff02::1 - Private, Multicast
- fd12:3456:789a::1 - Private, Unique Local
- ::ffff:192.168.1.1 - Private, IPv4-Mapped IPv6
